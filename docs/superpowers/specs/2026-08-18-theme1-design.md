# theme1 — Design Specification

**Date:** 2026-08-18
**Status:** Approved (design phase)
**Supersedes:** nothing — this is the founding spec

## 1. Purpose

Build **theme1**: an original, MIT-licensed admin dashboard theme that delivers the same
capability surface as the commercial template in `d:/webserver/www/sample_theme`, while sharing
**none** of its copyrighted design, markup, stylesheets, or artwork.

The existing template is **Vuexy** by **PIXINVENT** (`© 2021 Pixinvent, All rights Reserved`).
It is used here **only as a feature/requirements inventory**. Feature lists, page names, and
capability sets are not copyrightable; their expression is. Everything in theme1 is authored
clean-room from the requirements below.

### 1.1 Success criteria

| # | Criterion | Verification |
|---|---|---|
| S1 | Zero files derived from Vuexy CSS, SCSS, HTML, JS, or images | Manual review gate each phase |
| S2 | Every runtime dependency is MIT / BSD / Apache-2.0 / ISC / 0BSD / Unlicense | `scripts/license-audit.mjs` gates CI |
| S3 | Every shipped image/illustration/icon is generated by us or MIT-licensed | Asset manifest; no binary photos in repo |
| S4 | 121 unique pages render correctly in every layout permutation | Option-matrix build test |
| S5 | axe-core: 0 critical/serious violations on every page | CI a11y run |
| S6 | Lighthouse >= 95 performance on the dashboard page | CI perf run |
| S7 | Typical page ships < 400 KB JS and < 120 KB CSS gzipped | Bundle-size gate |
| S8 | LTR and RTL from a single stylesheet | Visual regression in both directions |

### 1.2 Non-goals

- Not a React/Vue component library. Output is static HTML, portable to PHP/Laravel/WordPress later.
- Not a backend. No PHP, no database, no auth implementation — demo data is static JSON.
- Not a pixel-clone of Vuexy. Visual similarity is explicitly avoided.
- Not shipping photographic imagery of people or products.

## 3. Decisions

| # | Decision | Rationale |
|---|---|---|
| D1 | **Static HTML + build pipeline** (Vite + Nunjucks + SCSS + vanilla ESM) | Drop-anywhere output; no per-page duplication; portable to any server language |
| D2 | **Bootstrap 5.3.x (latest) as base + our own token-driven component layer** | MIT; keeps tested grid/utility/a11y plumbing and vanilla JS plugins; visual identity stays ours |
| D3 | **"Calm Professional" identity** — indigo `#3D5AFE`, slate neutrals, Inter, 8px radius, soft elevation, comfortable density | Broad commercial fit; deliberately unlike Vuexy's violet + Montserrat |
| D4 | **All artwork generated as original SVG** | Zero licence risk, token-coloured, dark-mode native, ~200 KB instead of 13 MB |
| D5 | **No jQuery** | Removes 88 KB and the sole reason 12 legacy plugins exist |
| D6 | **Layout variants are runtime attributes, not file copies** | 1,656 files become 115 authored pages |
| D7 | **One stylesheet for LTR and RTL** via CSS logical properties | Eliminates the 3.5 MB `css-rtl` duplicate |

Any change to this table requires revising this spec before implementation continues.

### 4.2 Token system — three tiers

No component CSS hard-codes a value. Components read tier 3, which defaults to tier 2, which
resolves from tier 1.

**Tier 1 — primitive.** Raw values, no meaning, never referenced by components.

```
--t-indigo-50 … --t-indigo-950            11 steps
--t-slate-50  … --t-slate-950             11 steps
--t-emerald / --t-amber / --t-red / --t-cyan / --t-violet   11 steps each
--t-space-0 … --t-space-24                4px base scale
--t-size-xs … --t-size-6xl                1.200 minor-third type scale
--t-weight-400/500/600/700
--t-leading-tight/snug/normal/relaxed
--t-tracking-tight/normal/wide
--t-radius-none/sm/md/lg/xl/2xl/full
--t-shadow-0 … --t-shadow-5
--t-z-10 … --t-z-70                       base·dropdown·sticky·overlay·modal·popover·toast
--t-duration-fast/base/slow · --t-ease-standard/decelerate/accelerate
```

**Tier 2 — semantic.** Role-based. **The only tier dark mode, density, and presets swap.**

```
--t-surface-page / -raised / -sunken / -overlay / -inverse
--t-content-primary / -secondary / -muted / -disabled / -inverse / -link / -link-hover
--t-border-subtle / -default / -strong / -focus
--t-action-{primary,secondary,success,warning,danger,info}-{bg,bg-hover,bg-active,bg-soft,fg,ring}
--t-state-{success,warning,danger,info}-{bg,fg,border,icon}
--t-focus-ring: 0 0 0 3px var(--t-action-primary-ring)
--t-chart-1 … --t-chart-8                 categorical series, contrast-checked in both themes
```

**Tier 3 — component.** Per-component knobs, so retheming one component never touches another.

```
--t-btn-height-{sm,md,lg} · --t-btn-padding-x · --t-btn-radius · --t-btn-font-weight
--t-card-padding · --t-card-radius · --t-card-shadow · --t-card-border
--t-input-height · --t-input-border · --t-input-bg · --t-input-radius
--t-sidebar-width · --t-sidebar-width-collapsed · --t-navbar-height · --t-footer-height
--t-table-cell-padding-{comfortable,compact} · --t-table-stripe-bg
```

Dark mode redefines **tier 2 only** (~40 declarations). Density swaps a spacing multiplier.
Presets swap tier-1 hue ramps. **No component CSS changes for any of them.**

### 4.3 Bootstrap boundary

| Taken from Bootstrap 5.3 | Built by us |
|---|---|
| Reboot / normalize | Every component *skin* |
| Grid, flex, spacing, display, position, text utilities | The entire colour, type, spacing, elevation system |
| JS: Dropdown, Modal, Offcanvas, Tooltip, Popover, Collapse, Tab, Toast, ScrollSpy, Carousel, Alert | ~40 components Bootstrap has no equivalent for |
| Logical-property groundwork for RTL | Sidebar/navbar/customizer layout engine, theme store |

Our tokens **feed Bootstrap's CSS variables** (`--bs-primary`, `--bs-body-color`,
`--bs-border-color`, …) so utility classes and our components cannot drift apart. Imports are
selective — never `bootstrap.scss` wholesale. `$enable-shadows`, `$enable-gradients`,
`$enable-smooth-scroll` and related flags are set explicitly in `styles/bootstrap/_config.scss`.

### 4.4 Layout engine

All layout state lives in attributes on `<html>`:

```html
<html lang="en" dir="ltr"
      data-theme="light|dark|system"
      data-preset="calm"
      data-nav="vertical|horizontal"
      data-nav-skin="light|dark|semi-dark|bordered"
      data-nav-state="expanded|collapsed|hover|hidden|overlay"
      data-navbar="static|floating|sticky|hidden"
      data-navbar-color="default|primary|secondary|success|danger|warning|info|dark"
      data-footer="static|sticky|hidden"
      data-width="fluid|boxed"
      data-density="comfortable|compact"
      data-content-sidebar="none|left|right|detached-left|detached-right"
      data-motion="auto|reduced"
      data-contrast="normal|high">
```

`core/theme-store.js` is the single owner of that state:

1. An **inline, render-blocking boot snippet** in `<head>` reads `localStorage`, validates against
   an allow-list, and stamps the attributes **before first paint** — no flash of wrong theme.
2. Invalid or absent values fall back to documented defaults.
3. Mutations go through `themeStore.set(key, value)`, which validates, persists, applies, and
   emits a `theme:change` CustomEvent.
4. `data-theme="system"` subscribes to `matchMedia('(prefers-color-scheme: dark)')`.
5. `reset()` clears storage and restores defaults.

The customizer panel is a thin UI over this store and holds no state of its own.

**RTL needs no second stylesheet.** All directional CSS uses `margin-inline-*`, `padding-inline-*`,
`inset-inline-*`, `border-*-start/end`, and logical `text-align: start/end`. Direction-implying
icons (arrows, chevrons, back/forward) flip via a `[dir="rtl"]` transform on a single
`.t-icon--directional` class; clocks, media controls, and logos do not flip.

### 4.5 JavaScript architecture

- Native ES modules; no bundler-specific syntax in source.
- **Per-page entry points**, code-split by Vite. A page loads only what it renders.
- Heavy libraries (`ag-grid`, `apexcharts`, `fullcalendar`, `quill`, `leaflet`, `plyr`) are
  **dynamically imported on first use**, never in the shared chunk.
- Components initialise from `data-t-*` attributes through one delegated scanner, so markup
  inserted after load (AJAX, templating) is picked up automatically.
- No inline event handlers, no `innerHTML` with dynamic data, no `eval` — CSP-clean without
  `unsafe-inline` (the theme-boot snippet ships with a build-time hash).
- Every component module exports `init(root)`, `destroy(root)`, and a documented options object.

### 4.6 Build pipeline

**Vite 5** + `vite-plugin-nunjucks` + `sass` + PostCSS (autoprefixer, logical-property fallbacks,
cssnano).

| Script | Responsibility |
|---|---|
| `svg-gen.mjs` | Generates avatars, illustrations, patterns, and placeholder art from code at build time; token-coloured, dark-mode aware |
| `icon-sprite.mjs` | Builds one SVG sprite from Feather (MIT). No icon font, no FOUT, no 13 MB of webfonts |
| `token-export.mjs` | Single source produces `tokens.json` + `tokens.css` + `tokens.scss` (design-tool ready) |
| `license-audit.mjs` | **CI gate.** Fails the build on any non-permissive dependency; regenerates `THIRD-PARTY-NOTICES.md` |

Output: content-hashed assets, per-page JS chunks, critical CSS inlined, plain static HTML in
`dist/`. Partials map 1:1 onto server-side includes for later porting.

## 5. Visual identity — "Calm Professional"

```
PRIMARY   #3D5AFE   indigo       SURFACE page    #F6F7F9    raised #FFFFFF
SUCCESS   #10B981   emerald      CONTENT primary #111827    secondary #6B7280
WARNING   #F59E0B   amber        BORDER  default #E5E7EB
DANGER    #EF4444   red
INFO      #06B6D4   cyan
SECONDARY #64748B   slate

Type      Inter (SIL OFL, self-hosted, variable, subset latin + latin-ext)
Scale     1.200 minor third · body 14px · comfortable line-height
Radius    8px (md)
Elevation soft single layer: 0 1px 3px rgb(0 0 0 / .08)
Density   comfortable default; compact available
```

Dark mode is a **separately designed palette, not an inversion**: surfaces `#0F1117 / #16181D /
#1E212A`, primary lifts to `#6B82FF` to hold contrast on dark, and elevation switches from shadow
to surface-lightening. Every foreground/background pair in both themes is machine-verified at
**4.5:1 minimum** (3:1 for large text and UI boundaries).

The token layer is preset-ready; `calm` is the only preset built in this project.

## 10. Edge cases

**Component and page states.** Empty · loading (skeleton) · error · offline · partial failure ·
zero-results-after-filter · first-run vs populated · permission-denied variant of every page.

**Content stress.** 200-character names in table cells · unbroken URLs and email addresses ·
10-level menu nesting · counts of 0 / 1 / 999,999,999 · negative deltas · null and em-dash cells ·
500-row tables · 50-member avatar groups · 3-line badges and buttons · missing avatar images ·
very long file names in the file manager.

**Viewport.** 320 px to 3840 px · `prefers-reduced-motion` · 200% browser zoom · portrait tablet ·
landscape phone (navbar collapse behaviour) · print stylesheets for invoice, blog, and report.

**Combinatorial.** `RTL x dark x collapsed x horizontal-nav x boxed x compact x high-contrast`
must hold simultaneously. This is the failure mode of the source template's 14 static folders and
is tested here as an explicit matrix in Phase 13.

**Accessibility.** Keyboard-only path through every menu, modal, dropdown, tab, date picker,
stepper, and the kanban board (drag needs a keyboard alternative) · focus trap and restore ·
`aria-live` for toasts and validation · skip-to-content link · correct heading order ·
icon-only buttons labelled · 4.5:1 contrast in both themes, machine-verified.

**Internationalisation.** German/Finnish string expansion (+35%) must not break layout ·
RTL mirroring of direction-implying icons only · locale-correct number, date, and currency
formatting · pluralisation rules.

**Data correctness.** Timezone-correct calendar rendering · invoice totals computed in integer
minor units to avoid floating-point drift · date-range boundary handling · pagination at first
page, last page, and single-page.

**Security.** No inline event handlers · no `innerHTML` with user-controlled data · CSP-clean
without `unsafe-inline` · `rel="noopener noreferrer"` on every `target="_blank"` · no runtime CDN
requests · the source template's 4 `.php` files are not carried over.

## 13. Risks

| Risk | Impact | Mitigation |
|---|---|---|
| Unconscious copying of Vuexy's expression | Legal — defeats the project | Design from the token system outward, never from their CSS. Different palette, type, radius, elevation, class prefix (`t-`), and markup conventions. Review gate each phase. |
| Scope: 122 pages x ~95 components | Schedule | Strict phase gates; component library complete before pages consume it |
| ag-Grid at 935 KB | Performance budget | Lazy-loaded on its page only; excluded from the shared chunk |
| A dependency adopting restrictive terms on upgrade | Legal | `license-audit.mjs` runs in CI on every install |
| Combinatorial layout matrix explosion | QA cost | Matrix tested programmatically in Phase 13, not by hand |
| Generated SVG artwork looking generic | Product quality | Phase 06 is a dedicated design phase, not an afterthought |
